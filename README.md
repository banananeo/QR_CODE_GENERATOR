# QR//LAB

NOT YOUR BORING QR Generator

QR//LAB lets users create QR codes for different types of information and customize their appearance in real time.

## Features

- Generate QR codes in real time
- Supports:
  - Website
  - Plain Text
  - Email
  - Phone Number
  - Wi-Fi
- Customize QR code colors
- Change QR code size
- Change error correction level
- Adjust QR margin
- Choose different QR patterns
- Use predefined visual presets
- Gradient QR codes
- Download QR codes as PNG
- Copy QR content to clipboard
- Recently generated QR codes
- Recent QR codes are saved locally
- Dark/Light mode
- Responsive design for desktop and mobile
- Input validation
- Scan-friendly customization

## Tech Stack

- React
- JavaScript
- HTML
- CSS
- QR Code library
- Vite
